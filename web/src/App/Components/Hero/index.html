Local-first prompt infrastructure

Prompt Compiler

Compile intent into context-aware prompts.

Prompt Compiler prepares the question before the model answers. It turns rough intent, saved preferences, current goals, schedule, project memory, history, examples, templates, and output rules into a prompt that is ready to execute.

V0

One local compiler command, one context pack, one explicit PromptIR, one final prompt that can be inspected before it is sent to any provider.

compile.session 
$pcr according to my current goals and nearest schedule, compile a research prompt for assessment of my progress
