# Example Output

With:

```text
~/.pcr/context/goals.md
~/.pcr/context/schedule.md
~/.pcr/context/preferences.md
```

Run:

```bash
pcr compile "according to my current goals and nearest schedule, compile a research prompt for assessment of my progress"
```

The compiled prompt includes:

- task framing for progress assessment
- current goals
- near schedule
- preferences and recurring instructions
- positive and negative lessons from prompt history when available
- instructions for bottleneck analysis, risks, priority corrections, next actions, review questions, and structured markdown output
